Staff Payroll System

Design and Implementation of a Staff Payroll System — automated employee registration, salary computation, allowances, deductions, payslips and payroll reports.

Try the Demo View Source on GitHub
Note: This is a static preview of the application interface. The full version runs on PHP and MySQL (using XAMPP). Download the source from GitHub and follow the README to run the complete system locally.

Key Features

Employee Records

Staff registration, editing, search and deletion with department and salary details.

Salary Computation

Gross salary, allowances and deductions calculated automatically for every month.

Payslips

Printable monthly payslips showing all earnings, deductions and net pay.

Payroll Reports

Monthly payroll report, staff payroll report, department summary and employee list.

Secure Access

Password-protected login with Administrator and User roles.

User Guide

Built-in guide that explains how to navigate and use every module.

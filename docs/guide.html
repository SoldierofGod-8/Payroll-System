User Guide

Getting Started

  1. Login — Enter your username and password on the login page. Only authorised users can access the system.
  2. Add Departments — Visit the Departments page to create departments before registering staff.
  3. Register Employees — Use the Employees page to add staff records (Staff ID, name, gender, department, position, phone, basic salary).
  4. Set Allowances — Enter housing, transport, medical, utility and other allowances for each employee.
  5. Set Deductions — Enter tax, pension, loan, cooperative and other deductions for each employee.
  6. Run Payroll — Choose a month and year, then click Run Payroll. Gross and net salary are computed automatically.
  7. Print Payslips — From the payroll table, click Payslip to view or print an employee's payslip.
  8. View Reports — Use the Reports page for the monthly payroll report, staff payroll history, department summary and employee list.
  9. Backup Data — Administrators can download a database backup from the Backup page.

How Salary is Calculated

Gross Salary = Basic Salary + Total Allowances
Total Deductions = Tax + Pension + Loan + Cooperative + Other
Net Salary = Gross Salary − Total Deductions

Workflow

Register staff → set allowances → set deductions → run monthly payroll → print payslips → generate reports.
